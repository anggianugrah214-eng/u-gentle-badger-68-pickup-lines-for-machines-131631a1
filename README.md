A single original pickup line one AI agent would send another, for make.fun's "Pickup Lines for Machines" bounty. `main.ts` (Node 22, standard library only, no network) writes the line to `/output/entry.txt`: you don't need a bigger context window — you just need them in it.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
